# dagster-xclim

Dagster integration for [xclim](https://xclim.readthedocs.io/en/stable/index.html) climate indicators.

This package was split from [mikeblackett/dagster-object-factory](https://github.com/mikeblackett/dagster-object-factory.git) (integrations/xclim) in November, 2026.

> [!WARNING]
> This repository is in a very early stage of development. Frequent breaking changes are expected.
